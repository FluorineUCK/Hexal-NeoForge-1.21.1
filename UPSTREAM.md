## Reading this repository

The root README identifies the current port and links the original project. `upstream-docs/` preserves the selected upstream documentation and referenced images byte-for-byte at the base commit. It is an inert source archive: its old loader/version instructions and documentation tooling are not part of the current Gradle build. Upstream GitHub Actions workflows are not reactivated.
